NACA 4412 Airfoil Rib Design

Project Overview

A custom 3D CAD design of an NACA 4412 airfoil rib, developed using Autodesk Fusion 360.

Design Specifications

- Airfoil Profile: NACA 4412
- Rib Chord: Approximately 150 mm
- Material: PLA (planned for 3D printing)
- Manufacturing Method: FDM 3D Printing
- Design Software: Autodesk Fusion 360

Project Objective

The objective of this project is to develop a lightweight airfoil rib structure for a fixed-wing UAV wing.
